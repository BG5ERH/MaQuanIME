# 码圈输入法 0.1.77

**四端同版。** Windows、Linux、Android 从这里或官网下载；HarmonyOS 通过华为应用市场发行。

0.1.69 到 0.1.76 未在 GitHub 单独发布，内容已并入本版；完整逐版记录见
<https://maquan.app/changelog>。

## 整句更准

整句候选又准了一些，日常聊天里的提升比长句更明显。打字速度不变。

## 长按气泡换了顺序

手机上长按 26 键的字母键，气泡改成**左边大写、中间符号、右边小写**。手指按下去停在中间，
不动就是这个键上滑给的那个符号，往左滑大写、往右滑小写 —— 和九宫格那一路一致。
原来是「小写、大写、符号」，手指落在中间却高亮最左边，滑动方向和看到的排布对不上。
九宫格的气泡不变。

## 修复

- 手机上打成对的引号或括号时，光标不再往左跳几个字，会正常停在两个符号中间。

## 校验

```

Android  7e036ae10102a1c7246c8ac6f12440b0935fd20265d3d86af9219d5bb8e91851
```

Linux 也可以直接用软件源：<https://maquan.app/download>
