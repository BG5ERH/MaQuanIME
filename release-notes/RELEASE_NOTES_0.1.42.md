# 码圈输入法 Windows 0.1.42

本版是 Windows 候选一致性热修复；Android 与 Linux 当前正式版继续为 0.1.41，HarmonyOS 请从华为应用市场获取。

## 主要修复

- 修复 Windows TSF 快速启动时，热词小表与完整 JDX 切换时序不确定，导致同一编码在不同会话出现两套候选的问题。
- 快速启动层现在始终保留完整 JDX 精确编码查询，后台仍异步构建拼音辅助索引。
- 自然码 `qyjd` 多次新会话回归均稳定包含“清江、青酱、青鳉”；“张学友”等完整词库词条不再随启动时序消失。

## 测试

- 共享核心全量测试、全目标 Clippy `-D warnings` 和 Release 性能审计通过。
- 完整词库全拼逐键平均约 0.735 ms，自然码逐键平均约 0.660 ms；短码极端路径低于 5.2 ms。
- Windows x64/x86 双架构构建、PE 签名、真实安装注册与经典记事本 TSF 实输通过。
