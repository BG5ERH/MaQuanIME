# 码圈输入法 0.1.59

四端从同一份 0.1.59 核心重新构建，确认共享行为没有分叉。Windows、Android、Linux 与
HarmonyOS 的形码规则、两笔 30 键、标点顶字码长与 Z＋空格重复上屏保持一致。

## 正式版不再带调试页

Android 与 HarmonyOS 的正式包不再包含设置里的「调试」／「诊断」页。核心版本、数据根清单与
探针自检都是给开发用的，只保留在调试构建里。两端都用编译期判据，不存在"发布前忘了关"。

## 移动端

- 修复接上物理键盘（蓝牙或 USB）且关闭「全键盘模式」时，输入法窗口完全弹不出、点输入框
  毫无反应的问题。此前只能到系统设置里禁用再启用码圈才能恢复。
- 「全键盘模式」开关两个方向都生效；折叠状态下顶栏箭头一律是展开。
- 在线码表新增「更新」：装过的表出新版本时可直接更新并立刻生效（Windows 早已支持）。
- 剪贴板与常用语改为可滑动列表：单条可删可置顶，长按剪贴板条目存进常用语，「＋」可把
  输入框里的话存为常用语。

## 三码郑码

在线码表为 `2026.09.03.1`：候选顺序恢复为码表作者写下的顺序，例如 `afi` 上「〈〉〔」不再被
「々·」挤到后面。Windows、Linux 与移动端拉的是同一份目录。

## 校验

`SHA256SUMS` 与各安装包的 `.asc` 均由发布密钥 `DDEA0C1D2E89534339719927A6560A4AA577299D`
签名，公钥见本页 `MaQuanIME-Linux-Release-Public-Key.asc`。

```bash
gpg --import MaQuanIME-Linux-Release-Public-Key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c SHA256SUMS
```
