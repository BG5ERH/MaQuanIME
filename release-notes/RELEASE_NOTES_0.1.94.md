# 码圈输入法 v0.1.94

删不掉的候选现在能删，并能在「系统词库」里查询、隐藏和恢复；长按候选调顺序不再卡顿；支持宇浩·灵明、宇浩·日月；手机新增「机械革命」皮肤；鸿蒙版剪贴板可以自动记下复制的文字。

- **删除候选**：删掉的就是眼前这个词，自然码等双拼里补全出来的长词也能删；码表自带的词只是隐藏，不改动原码表。Windows 在候选上右键、手机长按删除时会再确认一次；Linux 照旧用删词快捷键。
- **新增「系统词库」**：在词库管理里输入完整字词或编码前缀，查询当前方案的系统词库，可以隐藏不想看到的词，也可以在「已隐藏」里随时恢复。不输入就不展开整个词库，每页最多 50 条。
- **调整候选顺序**：长按候选移到第几位时不再卡顿。
- **宇浩·灵明、宇浩·日月**：按方案规则输入——碰到元音或打满码长，当前字自动结束；没打完的简码可以用反引号（`）隔开；候选顺序与原码表一致。在「形码扩展」里下载或更新这两套码表后生效。
- **自定义音形码词条（Windows、安卓）**：在设置里用形码打字添加词条时，多音字按你这次实际打出的读音取码。
- **手机（安卓、鸿蒙）**：新增皮肤「机械革命」，深灰哑光、内凹键帽；长按模式键选「直接辅助」或「间接辅助」时会同时打开辅助码。
- **外挂字体（安卓、鸿蒙）**：导入的字体也用于剪贴板、常用语和词库管理里的字，复制进剪贴板的生僻字不再显示成空白或方框。
- **鸿蒙**：剪贴板可以自动记下复制过的文字（输入法处于「完整体验模式」时，在设置「键盘 › 剪贴板」里允许读取剪贴板，只在键盘弹出时读取；基础模式下系统不允许键盘读剪贴板）；基础模式下也能正常输入；「选择默认输入法」直接打开系统输入法设置；从旧版升级后，原来的设置和个人词库照常保留；「形码扩展」里体积较大的码表不再下载失败。
- **Linux**：设置程序「词库」页新增「系统词库 · 查询与恢复」。
