# 丙午年-中秋特别版 v0.1.87

月圆人团圆，打字更顺手。感谢大家持续反馈，祝中秋快乐！

- **桌面编辑更方便**：编码中间可用左右键移动、插入或修改；拼音和形码可分别设置编码显示区域，回车可选上屏编码或清除编码。
- **Windows 日常体验改进**：修复 Ctrl+Space 中英文切换、候选框定位及英文标点状态下的形码标点顶字；增加全半角与标点状态提示。设置窗口更宽敞、支持滚动和单实例，个人词库支持搜索与分页。
- **手机长句反查更清楚**：开启高级设置的附加键盘菜单后，上滑中／英键进入反查，再上滑退出。全拼及关辅码的双拼查当前形码，开辅码的双拼查辅助码。支持连续输入，编码单独换行显示，小三角展开后可滚动查看。
- **手机操作更顺手**：全拼短按仍切中英文，长按可选择收藏的拼音或形码方案；完善个人词库自动取码，改善安卓键盘高度稳定性和鸿蒙横屏候选显示。
- **Linux 安装更稳妥**：分别提供 Fcitx4 DEB、Fcitx5 DEB/RPM、IBus DEB/RPM；改进安装检查、文件选择与按路径导入。安装器不会为安装码圈自动删除现有依赖。
