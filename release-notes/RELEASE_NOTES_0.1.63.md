# 码圈输入法 0.1.63

**本次只更新 Android。** Windows 与 Linux 公网版本保持 0.1.62，HarmonyOS 通过华为应用市场发行。

## 九宫格连打

用两份真实语料各一万二千句做了实测（口语对话与新闻书面语），并以 26 键全拼作对照：

| | 句准确率 | 字准确率 |
| --- | --- | --- |
| 0.1.62 | 3.5% | 26.0% |
| **0.1.63** | **13.8%** | **60.0%** |

- 修复长句被切成一串无关字的问题。打「情况就是这么个」「也不知道在干什么」这类句子，
  此前会出成「奇尼苦熬和…」。
- 修复**输入超过十一个汉字之后完全没有候选**：更长的句子此前直接空白。

## 九宫格操作

- 左列改为显示**单个音节的几种读法**（如 `ping / qing / pin / qin`），点一个就确定这个字的
  读音，左列自动跳到下一个还有歧义的位置。
- 1 号键改为**「分词」**：`xian` 和 `xi'an` 的按键完全相同，用它手动断开就能打出「西安」。
- **长按数字键弹出气泡**，可直接输入大写字母、数字和小写字母。
- 右下角的回车/发送合并为**一个两行高的大键**；原来在九宫格上无效的「ab」键取消，颜文字键
  改为**「清空」**。
- 左列没打字时的标点可上下滑动选取：`，。？！～.…：；、@`
- 修复按住退格不能连续删除、从九宫格打开表情面板时表情显示不全。

## 云同步

- 恢复码改为**独立的醒目提示并可一键复制**。此前它和其他提示混在一起且无法复制，而恢复码
  一旦丢失就**无法找回** —— 云端只有用它加密过的密钥，服务器解不开。
