# 码圈输入法 0.1.78

**四端同版。** Windows、Linux、Android 从这里或官网下载；HarmonyOS 通过华为应用市场发行。

## 双拼打平舌不再出翘舌字

双拼下打 `s`、`z`、`c` 开头的字，候选里不再混进 `sh`、`zh`、`ch` 的字。
翘舌音仍由方案自己的按键给（自然码是 `u`、`v`、`i`），两边不再重复，
平舌的字也不会再被挤出首屏。

整句连打时同样有效：打「什么意思」不会再冒出「什么艺术」。

**全拼不受影响。** 全拼的单个字母是简拼首字母，`shi` 的首字母就是 `s`，
所以打 `s` 仍然能出「是」「上」，和以前一样。

## 三码郑码：最后一码是空格的字打得出来了

编码最后一位是空格的字，空格现在会**进入编码**（编码栏显示 `_`），再按一次空格才上屏。
同一个编码下的其它字这样才选得到 —— 以前第一个候选会被直接顶上屏，后面的根本没机会出现。

符号不变，仍然是一个空格直接出。
