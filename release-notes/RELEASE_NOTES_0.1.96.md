# 码圈输入法 v0.1.96

形码整句 AI 预测与桌面词库管理升级，支持拆分学习和自定义日期时间输入。

- 形码整句 AI 预测：在输入过程中提供语句建议，辅助完成日常文字表达。
- Windows 词库管理：支持批量分类、按分类导入与独立窗口，集中整理个人词库和自定义编码。
- 拆分学习：为自选形码方案导入拆分文件，在候选中查看字根，辅助学习和记忆编码。
- 自定义日期时间输入：为常用日期和时间格式设置专属编码，快速输入所需内容。
