## 这一版修了什么

- **拼音候选排序**：自然码 `ken` 上「可、课、可能」等常用字被三个生僻字挤到前面，`nve` 打「女儿」时满屏生僻字。原因是补全候选池里的单字没有按音节边界过滤，落进来一批读音根本对不上的字。全拼与各套双拼都受影响。
- 扩展区汉字（U+20000 以上）此前被判定成「不是汉字」而绕过读音校验，现在与基本区一视同仁。
- **三码郑码简码候选按简码级别排序**：同一个编码下，一级简码排在二级前面，不再按码表里的行号先后。在线码表目录为 `2026.09.04.1`。
- 移动端在线码表列表直接显示「已装 &lt;版本&gt;」，装的是哪一版、能不能更新，界面自己写出来。
- 华为应用市场的离线包第一次带上与官网同一份码表目录。
