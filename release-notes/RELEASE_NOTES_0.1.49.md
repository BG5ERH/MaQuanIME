# 码圈输入法 0.1.49

本次更新统一发布 Windows、Android 与 Linux 0.1.49；HarmonyOS 同步完成正式构建，继续通过华为应用市场分发。

## 主要变化

- 形码设置新增“两笔 30 键”，默认关闭。开启后输入首码，逗号、句号、分号、斜杠参与编码；形码 2/3 选与普通符号顶字会自动关闭。
- 移动端离线目录加入超强两笔、超强快码、超强飞码；三点菜单补充“形码设置”“拼音设置”快捷入口。
- 关闭旧的 `zz` 系列符号辅助状态。`zz` 不再被输入法功能抢占，始终交给当前郑码或用户导入码表查询。
- Android、HarmonyOS 的本机码表导入统一使用共享核心；用户码表导入后可以改名和删除。
- 四端版本统一为 0.1.49，共享移动 ABI 为 14。

## 验证

- 用户提供的 `uggx.dict.yaml` 经共享导入器生成 147,117 条记录；`zz` 有 87 个候选，前五项为“出、丝、𢇅、继续下去、出于”。
- 共享核心通过格式检查、全目标 Clippy 与 Release 工作区测试；引擎主测试 172 项通过、2 项按设计忽略。
- Android 正式 APK 在 Android 15 模拟器连续唤起键盘 30 次，无崩溃、ANR 或输入法进程消失。
- HarmonyOS 正式 HAP 已安装到 HarmonyOS 7.0 模拟器，并从系统文件选择器成功导入用户郑码、立即设为当前码表。
- Linux 四个包分别在 Debian 13、Fedora 44 完成 IBus / Fcitx5 安装与实际“你好”上屏。
