# 码圈输入法 0.1.82

2026-09-11 · Windows / Linux / HarmonyOS 正式版。Android 保持 0.1.81。

- Windows 从首次查询起使用完整词库，修复冷热加载状态变化时已调频整句候选缺失的问题，增加进程索引缓存容量。
- Windows、Linux 新增独立方案管理：导入极点 .mb、冰凌文本和 Rime 静态词典；修改已导入 / 下载方案的显示名称，选择方案、删除安装副本。改名不改变码表内容和个人调频。
- 自定义双拼增加名称编辑，支持 schema 导入导出、试打解码及返回方案管理；名称同步到选择列表。
- Linux 提供 x86_64 / amd64 的 Fcitx5、IBus 两种前端，分别有 DEB、RPM；原签名 APT / DNF 软件源同步更新。两种前端包不要同时安装。
- HarmonyOS 提供 arm64-v8a / x86_64 核心的在线正式签名 HAP；侧载仍取决于设备及签名分发授权范围，未做鸿蒙真机安装验证。
- 模型及模型信息不变。Windows 安装后请关闭重开正在使用输入法的应用，避免旧进程仍驻留旧组件。

安装包及校验签名见本 Release；官网：[下载](https://maquan.app/download)。
