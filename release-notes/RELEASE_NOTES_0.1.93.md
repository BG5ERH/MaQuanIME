# 丙午年-国庆特别版 v0.1.93

形码整句只出打得出的字、不再提前补词，音形码多音字按读音连打，第一次开启准备快一倍；全拼可以完整音节与简拼混打；新增「高级编辑」，含快捷日期时间；手机数字键盘可以计算。

- **形码整句**：候选里不再出现只凭前两三码猜出来的字，也不再在后面补出还没打的字词，按到哪出到哪；打完整码时首选更稳；通用规范汉字表与 GB2312 都没收的生僻字排到后面。部分码表在全识别下个别按键明显卡顿的问题已解决。
- **音形码整句**：多音字按词语的实际读音取码，「系统」「长大」这类词句照读音连打就能出来。整句里不再接受每个字都有、与读音无关的通用编码（部分音形码以 i、z 开头的那一条），请按读音打；单字与普通形码模式不受影响。
- **形码整句准备更快**：第一次开启（或换码表后）准备索引的时间缩短一半以上，占用内存更少。从旧版升级后，第一次使用形码整句会重新准备一次，请稍候。Windows 会自动清理同一码表留下的旧索引文件（每份约 85 MB）。
- **全拼**：完整音节和声母简拼可以混着打，四字词、多字词更容易一次打出（如 hlihs、hualihs 打出「花里胡哨」）；zh、ch、sh 打到一半时首页仍是单字。
- **新增「高级编辑」**（高级设置 → 高级编辑）：用一段文字开启不常用的功能，默认都关，写错会指出第几行；以前保存过的内容打开时会自动补上新增的功能段，可随账户同步。目前有：
  - 形码「引导键唯一上屏」：首键是 a、i、o、u、v 等引导键时，不论码长，候选唯一就上屏；
  - 「快捷日期时间」：打 date、time 出按自己设定格式的日期、时间；
  - 形码自造词取码规则：可自定义自造词怎样取码，多音字按本次键入和前后词语挑选全码。
- **快符（Windows、Linux）**：连按两次引导符时按当前标点状态输出，中文标点下出「；」；快符引导符与二三候选键、翻页键同键时不再误报冲突。
- **二三候选键与标点顶字**：两者同时开启时，有第二、第三候选就先选候选，没有时才顶字上屏标点。
- **拼音「AI 候选重排」**：换用新模型，体积约为原来的三成，整句更准（仍默认关闭）；带调双拼方案里的个人词在开启重排时不再被挪下去，候选栏长按可以删除。
- **手机（安卓、鸿蒙）**：数字键盘新增「计算」——「#」换成「+」，「中/英」换成「计算」，输入算式即出「算式=结果」和「结果」，空格或「=」上屏，回车上屏算式原文；改了某个键的副字符后，其余键的（）“”等成对符号照旧成对。
- **设置**：遇到更新版本才有的设置项时跳过并原样保留，不再提示「设置格式无效」；Windows 安装时先关闭正在运行的设置程序。
- **Linux**：设置程序「高级设置」页新增「高级编辑…」。
