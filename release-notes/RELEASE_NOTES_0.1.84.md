## 2026-09-13 四端更新

Windows、Android、Linux、HarmonyOS 正式版同步更新。

- 双拼辅助码新增直接模式：每个字在双拼两键后按需补 0、1 或 2 位辅助码，可整句混用；自造词参与。只有间接模式显示引导符设置。
- 修复直接辅助码下自造词简码失效，保留双拼自造词简拼开关和 z/c/s 与 zh/ch/sh 的匹配约束。
- 候选设置新增词组联想，形码与拼音独立开关、默认关闭。上屏后从当前本地词库和个人词库查询后续文字，选中只追加后续部分；继续输入或切换输入框退出旧联想。
- 优化全拼、双拼、辅助码的整句查询和冷启动，形码混码索引增加经过校验的磁盘缓存。
- 鸿蒙调整面板复用和异步会话加载，隔离输入框之间的待处理按键，修正应用切换时重复加载及显示时序。
- 修正宿主临时指定拼音方案时，运行时简拼开关未使用实际选定方案的问题。
- 保留快符、个人词库按方案导入导出、整句标点、首道双拼和首右辅助码等既有功能；模型、模型信息及来源声明不变。
