# 码圈输入法 v0.1.95 更新日志

发布日期：2026-10-24　平台：Windows、Linux、Android、HarmonyOS

新增 AI 写作、快速润色与预测、词库分类和高级剪贴板，完善官方同步、手机键盘和皮肤使用。

- 账户页统一显示「码圈官方」，可从列表选择已有服务器，也可新建自建服务器。官网和输入法使用同一个官方账号。
- 电脑新增 AI 写作（Ctrl+3）、快速润色（Ctrl+4）和高级剪贴板与常用语（Ctrl+5）。需要在设置中启用；AI 使用自己的服务和密钥，结果不会自动发送。
- 新增 AI 预测，在候选旁提供写法建议，可单独开启或关闭。
- 个人词库支持分类，形码词可选择是否参加整句；超强系列造词、形码整句和双拼辅助码选字更准确。
- 上下键可挑选候选，Ctrl+数字可调整顺序；手机外接键盘支持 Caps Lock、F10–F12 和全键盘模式。
- 个人云皮肤可在各端使用，支持 .mqtheme 导入；Linux 补齐皮肤导入导出。
- 鸿蒙在线版改用紧凑的 AI 问答界面，长按回车可直接润色；修复关闭窗口误报屏幕空间不足。
- Windows 修复覆盖升级后仍显示旧界面的问题。安装后请重新打开正在使用输入法的应用；Linux 安装后重启，安卓沿原渠道覆盖安装。鸿蒙以应用市场实际上架版本为准。
