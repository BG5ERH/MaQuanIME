# 码圈输入法 0.1.68

**四端同版。** Windows、Linux、Android 从这里或官网下载；HarmonyOS 通过华为应用市场发行。

## 五笔、郑码也能连打整句

新增「形码智能整句（实验）」：打开之后，每个字只打前两码，一句话连着打完，整句候选直接排在第一条。

- 编码区按每个字分组显示，一眼看得出打到第几个字。
- 打满全码仍然出那个字，原来的打字习惯不用改。四码同时也可能是一个两字词，词排在前面、字紧跟其后，按数字键选。
- 开关在**形码设置**里，默认关闭，可以随时关回去。第一次打开需要在后台准备一次，手机上约几十秒、电脑上约十几秒，这段时间输入法照常可用；准备完成后重新打开一次键盘即可。这一步只做一次。

用法详见[使用说明](https://maquan.app/guide/smart-sentence-and-local-ai)。

## AI 候选重排

新增「AI 候选重排（实验）」：在已经猜出来的那几条候选之间再排一次序，让更合适的那条靠前。它只调整名次，自造词、调频和你手动调过的词序都不受影响。开关在**拼音设置**里，默认关闭。

拼音长句的候选也比上一版更准，句子越长越明显。

以上都在你自己的设备上完成，输入内容不会被发送出去，断网也照常工作。
