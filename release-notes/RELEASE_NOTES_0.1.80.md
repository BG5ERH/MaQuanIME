# 码圈输入法 0.1.80

Windows、Android、Linux 与 HarmonyOS 四端正式版。

- 形码整句提供全识别（默认模式）和两码模式。全识别允许每个字使用前 2、3、4 码混合连续输入；两码模式保留每字前两码的固定节奏。
- 全识别按当前首选候选的字界显示编码分隔，两码模式每两码一组。分隔仅用于显示，无需手动输入空格。
- 支持词组和自定义词组参与整句，修复移动核心用户词增删后当前会话候选未刷新的问题。
- Linux 补齐五套内置双拼辅助码、引导键选择和自定义 UTF-8 TSV 辅助表导入。仅对双拼生效，不改变全拼。
- Android 保留中英文副字符独立编辑、合并导入导出恢复，以及长候选换行。
- 模型文件、来源声明与原有模型信息保持不变。

形码设置中开启智能整句后选择模式。首次需要准备索引；已有明确关闭设置会保留。Linux 改完设置点击「立即重载输入法」。

下载：[官网四端下载](https://maquan.app/download) · [整句使用说明](https://maquan.app/guide/smart-sentence-and-local-ai)

Windows 提供正式安装器；Android 提供正式签名 APK；Linux 提供 IBus/Fcitx5 的 DEB、RPM 和签名；HarmonyOS 提供官网在线正式签名 HAP。HAP 安装受设备系统和分发限制，并非 Android APK。已安装早期 Android 0.1.80 的用户可手动下载覆盖安装，建议先备份个人数据。
