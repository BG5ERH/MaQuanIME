# 码圈输入法 0.1.79

Windows、Android 与 Linux 正式包已发布。HarmonyOS 请通过华为应用市场获取。

## 辅助码一码收尾后继续连打

辅助码只输入一码时，再按一次自己设置的引导键，就可以继续输入后面的字。两码辅助定字的原有用法保留。

## 个人词支持未打完的尾音

已保存的个人词在最后一个音节尚未打完时也能找到。例如保存「测试词条」后，自然码输入 `ceuicit`、全拼输入 `ceshiciti` 即可召回，不必把最后一个音节全部打完。

## 自动造词使用说明

连续单字可以先组成临时词；达到确认次数后才永久保存。测试时再次完整选中临时词，也会计入确认次数。

普通组词行为保持不变。各模式、辅助码保存规则与手工添加方法请看[自动造词与个人词库使用说明](https://maquan.app/guide/auto-phrase-and-personal-dictionary)。
