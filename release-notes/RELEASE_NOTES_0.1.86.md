# 码圈输入法 0.1.86

2026-09-23 · Windows / Android / Linux 正式发行；HarmonyOS 应用市场实际更新以审核上架为准，本页不提供 APP/HAP 直装附件。

## 9 月 24 日安卓补充更新

词库管理 → 形码 → 选择码表 → 手动添加词条：输入词条后会尝试自动带出当前方案的编码，不再限于五笔。编码可以直接修改；修改词条后重新自动取码。无法自动取码的方案仍可手工填写，自然龙、汉心龙不猜测词码。

版本仍为 0.1.86，重新下载 Android APK 覆盖安装即可，无需卸载。其他平台附件没有变动。

## 怎么使用新增功能

- **形码字词**：改善完整字词连续输入时的首选稳定性，保留原码简码习惯和个人词序，不设 8 码硬分界。希望严格按原表打字词，可选正常模式和固定词序。
- **Ctrl+1 辅助码菜单**：按 1 关闭、2 直接辅助码、3 间接辅助码，默认关闭。具体辅助码表和引导符在拼音设置选择；新增汉心双码辅助码。
- **Ctrl+2 形码模式菜单**：按 1 正常、2 整句、3 单字优先。两组快捷键均可在分组后的快捷设置中修改，Esc 取消。
- **Alt+Z 反查**：形码下按 Alt+Z，输入拼音查看候选旁的当前形码；Esc 退出。Windows 安装更新后请重新打开原有应用窗口；默认不占 Ctrl+Z 撤销。
- **候选与词序**：候选设置中可分别调整形码、拼音候选数量。「常用词组排前面」改称「词组自动调频」；要保持原表顺序请选择固定词序。
- **手机上滑文字**：在当前皮肤的副字符编辑中设置英文 . 或 .com，保存并重新弹出键盘后按原文输出，不再随中文状态变成句号。修正长按方案列表顶部显示及导入龙码方案标识问题。
- **自然龙／汉心龙**：继续采用原码表路线，可在线下载或自行导入维护；个人词库需要时手工填写正确词码。

## Linux 分流

Fcitx4 提供独立 DEB；Fcitx5 与 IBus 各提供 DEB/RPM，仅支持 x86_64/amd64。三套码圈前端不要混装，按本机实际框架选择；Fcitx4 状态菜单比另外两套少，可通过快捷键和设置中心操作。

官网统一安装脚本可以自动检测，也可指定 `--framework fcitx4`、`fcitx5` 或 `ibus`；不明确时停止，不自动替换系统输入法框架。安装后请重启系统。

## MaQuanTableTool 码表转换工具

另附独立版本 0.1.0 Windows x64 便携工具。支持 Rime 静态词典、冰凌文本码表和极点 .mb；可检查问题、另存修复、导出并回读校验。先备份原表、使用新文件名保存，自动修复之后仍需检查报告。不是任意私有格式间的万能转换器。
