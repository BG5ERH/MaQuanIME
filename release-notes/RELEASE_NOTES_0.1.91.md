# 丙午年-国庆特别版 v0.1.91

拼音候选顺序恢复正常，修正一批词的读音；新增「自然龙整句」「汉心龙整句」；自定义双拼可以设计带声调的键位。

- **拼音**：上一版部分词语的候选顺序变乱，现已恢复；「策略」用 celue、celve 都能打出，「大略」「虐待」「略过」等词可以直接打；金匮要略、宝藏、族长、重叠、憔悴等词的读音改回正确。
- **新增拼音方案「自然龙整句」「汉心龙整句」**：两键一个带调音节，可以连打整句，也能接直接辅助码；形码里原来的自然龙、汉心龙码表照常可选。
- **自定义双拼**：设计器新增「带调模板」，可以设计键位含声调的双拼方案；试打时每两键列出能打出的带调音节。
- **导入码表**：只含全角空格的词条也会保留，不再被当成空行丢掉。
- **音形码自动造词**：多音字按这一次实际输入的读音取码。
