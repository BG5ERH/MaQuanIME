# 丙午年-国庆特别版 v0.1.89

欢度国庆，整句更准。感谢大家持续反馈，祝国庆快乐！

- **电脑版新增「整句模型」**：Windows 在设置的「高级设置」、Linux 在设置程序的「高级设置」页，可从标准模型换成高级模型，形码整句和拼音连打都更准。点「下载高级模型」，看过使用条款并确认后下载（约 21.5 MB），完成后自动选上；Windows 再点「应用」，Linux 回到输入框即生效。形码需先在形码设置里开启智能整句。可随时改回标准模型、检查更新或删除；手机端暂用标准模型。
- **整句更稳**：长句不再被几个零散的整码字拼出的错句顶掉，三四个字的词照旧优先；音形码方案里的多音字按词语读音取码，「不能区分」「长大」这类词句可以连着打出。
- **五笔类方案按 z**：首屏直接是常用标点「。，、；：？！」，不再先出现一条标点目录。
- **拼音也能标点顶字**（Windows、Linux）：打拼音时直接按句号、引号等标点，先上屏当前首选再输出标点；与形码共用「标点顶字」开关，拼音设置里可以勾选。
- **Windows**：大写锁定打开后字母按大小写正确输出；开启「标点顶字」时，按回车左边的引号键先上屏首选再输出中文引号，关闭时仍是选第三个候选。
- **手机皮肤**（安卓、鸿蒙）：新增「简约黑白」（宽体与经典两种布局，三点菜单长按切换）和「简黑」；外观里可开启「跟随系统主题」，深色时自动用简黑；副字符长按气泡统一横排。
- **手机体验**：安卓在形码整句与双拼辅码之间切换不再卡顿；改善安卓横屏起笔时键盘上跳；安装包去掉误带的码表，体积更小。
- **Linux**：设置程序新增「高级设置」页，可下载与切换整句模型；继续分为 Fcitx4 DEB、Fcitx5 DEB/RPM、IBus DEB/RPM。
