# 码圈输入法 0.1.65

**四端同版。** Windows、Linux、Android 从这里或官网下载；HarmonyOS 通过华为应用市场发行。

## 全拼打字卡顿修复

个人词库里只要有自造词，全拼连打就越来越慢，句子越长越明显；删掉词库就好了，同步回来又复发。双拼不受影响。

用真实词库（49 条自造词）实测逐键延迟：

| | 中位 | 最坏一键 |
| --- | --- | --- |
| 0.1.64 | 710 ms | 4173 ms |
| **0.1.65** | **1.48 ms** | **3.31 ms** |

根因是查「这个字有哪些读音」时会把几万条单字索引整个线性扫一遍（约 2 ms），而个人词的简拼校验在一次按键里要问上千次。改成一次扫描建好反查表；另外两处「对每个前缀长度重跑一遍回溯」也收敛成一次搜索。

## 设置中心

- 「导入个人词库」「导出个人词库」「同步最新词源」此前点了只提示「尚未切入新服务」，现在都能用了。
- 新增**「同步个人词库」**。它和「同步最新词源」是两件事：前者把你自己造的词与云端保险库对一遍，后者拉取官方增量词库。未登录或未开启同步时会直接说明原因。
- 词库管理加了一行说明：个人词库统一按全拼编码保存，选择双拼方案时会自动转换，导入导出同样是全拼格式。
- 拼音设置最后一行说明文字超出边框被截断，已加宽。

## 移动端

- 符号面板「中文」页的分号、逗号、句号等此前会跟着中英标点开关变成半角。现在两页都按页面标的来 —— 中文页出全角，英文页出半角。
- 默认皮肤上 **H 与 J 的引号此前完全一样**（都是一对左右引号）。现在 H 给一对、J 给一个。
- 主题外观新增**「编码区字号」**。候选字号和键面字号一直可调，唯独打字时一直盯着看的编码那一行不能调。
